Configure Edge Function secrets (MT_IP, MT_USER, MT_PASS) then test below.
Edge Function Secrets
These are set via Supabase CLI, not in this UI:
supabase secrets set MT_IP=192.168.88.1
supabase secrets set MT_PORT=80
supabase secrets set MT_USER=admin
supabase secrets set MT_PASS=yourpassword
supabase secrets set MP_ENV=live
supabase secrets set MP_KEY=consumer_key
supabase secrets set MP_SECRET=consumer_secret
supabase secrets set MP_SHORTCODE=174379
supabase secrets set MP_PASSKEY=your_passkey
supabase secrets set MP_CALLBACK_URL=https://xxx.supabase.co/functions/v1/netbill/mpesa-callback
supabase secrets set AT_USERNAME=sandbox
supabase secrets set AT_KEY=your_at_key
supabase secrets set ISP_NAME=Jamii Fibre
supabase secrets set ISP_PAYBILL=247247
M-Pesa Daraja Setup
1. Register at developer.safaricom.co.ke
2. Create an App → Get Consumer Key & Secret
3. Set secrets via CLI (see MikroTik tab)
4. Set MP_CALLBACK_URL to your Edge Function URL + /mpesa-callback
5. Register C2B URLs on Daraja for Paybill auto-matching

Flow: Customer selects plan → portal calls Edge Function → STK Push sent → customer enters PIN → Daraja calls your callback URL → Edge Function connects IP on MikroTik automatically.
Africa's Talking SMS
1. Sign up at africastalking.com
2. Set AT_USERNAME, AT_KEY, AT_SENDER as Edge Function secrets
3. SMS are sent automatically on: payment success, session expiry

Templates are in the edge function. You can edit edge-function.js to customise messages.
One-Time MikroTik Firewall Setup
Run these commands ONCE in MikroTik Terminal (Winbox or SSH). This is all you need — NetBill manages everything else automatically via REST API.
/ip firewall address-list add list=netbill-blocked address=0.0.0.0/0 comment="Default block all" # Allow active NetBill customers (NetBill adds/removes IPs here) /ip firewall filter add chain=forward src-address-list=netbill-active action=accept place-before=0 comment="NetBill - Allow Active" /ip firewall filter add chain=forward dst-address-list=netbill-active action=accept place-before=1 comment="NetBill - Return Traffic" /ip firewall filter add chain=input src-address-list=netbill-active action=accept place-before=0 comment="NetBill - Allow Active Input" # Allow access to the portal (so people can pay even without internet) /ip firewall filter add chain=forward dst-address=YOUR_PORTAL_SERVER_IP action=accept place-before=0 comment="NetBill - Allow Portal" # Drop everything else (put this AFTER your existing rules) # /ip firewall filter add chain=forward action=drop comment="NetBill - Drop Unpaid" # Enable REST API (if not already on) /ip service enable www # Create a dedicated API user (recommended) /user add name=netbill-api password=STRONG_PASSWORD group=full comment="NetBill API User"
⚠ The DROP rule is commented out. Only enable it when you are ready — it will cut off anyone not in the netbill-active list. Test thoroughly first.
